  turns, one green marker stays at the top, red is the card's **N** alone.

## Gotchas learned
- **A test that has never run is not a test.** AC150 asked for a token
  without dashes while the code produced `UUID().uuidString`'s dashed form,
  and it stayed wrong for hours: the phone was off the bus, and the standalone
  harness covered the **redaction**, not the **token**. The trace said
  *"151 rows ↔ 151 test names, the same set"* — true, and it says nothing
  about whether a test's **body** is right.
- **A phone off the USB bus is still reachable over Wi-Fi.** A waiter that
  waits for the literal word *"connected"* waits for ever, and
  *"disconnected"* contains *"connected"*. Test the **link**
  (`devicectl device info lockState`, `xcodebuild -showdestinations`), not
  the word.
- A **broken log capture reads as a missing callback** — check the line count
  before believing what is missing from it.
- `headingAccuracy` is the heading's **error**, not its noise.
- A filter that counts **readings** is not a filter.
- A **magnetic needle and a rotating card are two different instruments**.
- An `NSError`'s description carries the URL that failed, and the URL carries
  the token.
- 32 bits is not a lock on a LAN-served stream — 128.
