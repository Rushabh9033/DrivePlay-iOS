## Gotchas learned
- A **broken log capture reads as a missing callback** — check the line count
  before believing what is missing from it.
- `headingAccuracy` is the heading's **error**, not its noise.
- A filter that counts **readings** is not a filter.
- A **magnetic needle and a rotating card are two different instruments**.
- An `NSError`'s description carries the URL that failed, and the URL carries
  the token.
- 32 bits is not a lock on a LAN-served stream — 128.
