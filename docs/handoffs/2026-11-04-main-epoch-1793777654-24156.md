## Decisions made
- The compass is a **heading indicator**, not a magnetic compass: the card
  turns, one green marker stays at the top, red is the card's **N** alone.
- The **arrival** time is the filter's clock, not the reading's own stamp.

  course takes over — a needle that follows an uncertain reading points the

## Gotchas learned
- A **broken log capture reads as a missing callback** — `idevicesyslog` exits
  when the phone drops off the bus; check the line count before believing what
  is missing from it.
- `headingAccuracy` is the heading's **error**, not its noise (27.58° on a
  phone lying flat) — a filter cannot fix an error, only a gate can.
- A filter that counts **readings** is not a filter (the magnetometer delivers
  several times a second, the GPS once a second).
- A **magnetic needle and a rotating card are two different instruments** —
  the app had both, and they disagreed about north.
- An `NSError`'s description carries the URL that failed, and the URL carries
  the token — log the host and the file name instead.
- 32 bits is not a lock on a LAN-served stream — 128.
